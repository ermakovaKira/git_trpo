Что такое CMS

CMS - «система управления контентом» (движок) – написанная PHP-программистами основа для сайта, с помощью которой вы сможете управлять сайтом не зная HTML и CSS.

Однако, для того чтобы сделать сайт с помощью CMS потребуются услуги и программиста, и дизайнера, и верстальщика.

Какие бывают cms

Бывают различные системы управления контентом: для интернет-магазинов, для блогов, для форумов и т.д.

Примеры cms

Примеры популярных CMS: Joomla, WordPress, PhpBB.

CMS-ки бывают платные и бесплатные.

PHP и JavaScript

Языки программирования PHP и JavaScript позволяют сделать сайт динамичным.

Виды скриптов

Для этого пишутся скрипты (англ. script - «сценарий»). Скрипты бывают двух видов:

  • те, которые выполняются на сервере. Это скрипты на языке PHP. На нем пишутся CMS-ки.
  • те, которые выполняются прямо в браузере. Это скрипты на языке JavaScript.
